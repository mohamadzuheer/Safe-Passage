# My API Keys & Credentials Checklist

This checklist organizes every credential and account you need to take complete ownership of your ReliefRoute instance on Windows 11.

---

## 1. Essential Credentials (Tier 1: To Run Locally)

### 🤖 Google Gemini API Key
- **Variable Name:** `GEMINI_API_KEY`
- **Target File:** `backend/.env`
- **Purpose:** Powers AI alert triage (Sentinel), operational disaster briefings, and regional translation (Telugu/Hindi) for truck drivers.
- **Cost:** Free tier is available and sufficient for local development.
- **Website:** [https://aistudio.google.com/apikey](https://aistudio.google.com/apikey)
- **Account Creation Steps:**
  1. Open [Google AI Studio](https://aistudio.google.com/apikey).
  2. Sign in with your personal or work Google account.
  3. Click the blue **"Create API key"** button.
  4. Select or create a Google Cloud project when prompted.
  5. Copy your generated key (starts with `AIzaSy...`).
  6. Open `backend/.env` in your editor and replace `PASTE_YOUR_GEMINI_API_KEY_HERE` with your key:
     ```ini
     GEMINI_API_KEY=AIzaSyYourActualKeyHere
     ```

## 2. Local Database & Cache Credentials (Tier 1: Managed Locally by Docker)

The project includes a ready-to-use local `docker-compose.yml` that runs PostgreSQL 16 with PostGIS 3.4 and Redis 7 on your laptop. You do **not** need to sign up for external cloud database providers for local development.

- **PostgreSQL Connection:**
  - **Variable Name:** `DATABASE_URL`
  - **Target File:** `backend/.env`
  - **Value Already Configured:** `postgresql://reliefroute:reliefroute@localhost:55432/reliefroute`
  - **Container Port:** `55432` (avoids conflict with default Windows Postgres port 5432)
- **Redis Connection:**
  - **Variable Name:** `REDIS_URL`
  - **Target File:** `backend/.env`
  - **Value Already Configured:** `redis://localhost:6380/0`
  - **Container Port:** `6380` (avoids conflict with default Redis port 6379)
- **Valhalla Routing Engine:**
  - **Variable Name:** `VALHALLA_URL`
  - **Target File:** `backend/.env`
  - **Value Already Configured:** `http://localhost:8002`

## 3. Operational Security Secrets (Tier 1: Auto-Generated Locally)

- **Operator Bootstrap Token:**
  - **Variable Name:** `OPERATOR_TOKEN`
  - **Target File:** `backend/.env`
  - **Purpose:** Used to authorize the initial creation of the first Duty Officer account and automated administrative scripts.
  - **Action:** You can leave this commented out in `backend/.env`. The startup script (`infra/dev/stack.ps1`) automatically generates a secure 64-character hexadecimal token on first launch if one is not already present.
- **Vehicle Enrolment Code:**
  - **Variable Name:** `ENROLMENT_CODE`
  - **Target File:** `backend/.env`
  - **Purpose:** Authorizes driver hardware or legacy devices to connect.
  - **Action:** Auto-generated by `stack.ps1` if left unset.

## 4. Optional Integrations (Tier 2: Advanced Feeds & Notifications)

All of these services are completely optional. The application will run smoothly without them by using fallback mockers or keeping optional notification channels disabled.

### 🛰️ NASA FIRMS (Fire Information for Resource Management System)
- **Variable Name:** `FIRMS_MAP_KEY`
- **Target File:** `backend/.env`
- **Purpose:** Ingests live satellite thermal anomalies (wildfires/forest fires).
- **Website:** [https://firms.modaps.eosdis.nasa.gov/api/map_key/](https://firms.modaps.eosdis.nasa.gov/api/map_key/)
- **Instructions:** Request a free MAP KEY by entering your email on the NASA portal. Leave blank if not needed.

### 📱 Twilio (SMS & WhatsApp Notifications)
- **Variable Names:**
  - `TWILIO_ACCOUNT_SID`
  - `TWILIO_AUTH_TOKEN`
  - `TWILIO_FROM_NUMBER`
- **Target File:** `backend/.env`
- **Purpose:** Sends real SMS and WhatsApp dispatch notifications to drivers and warehouse managers.
- **Website:** [https://www.twilio.com/try-twilio](https://www.twilio.com/try-twilio)
- **Instructions:** Sign up for a Twilio trial, purchase a phone number, and copy the SID and Auth Token from your console. Leave blank if testing locally without SMS.

### 🔍 Langfuse (LLM Observability & Tracing)
- **Variable Names:**
  - `LANGFUSE_PUBLIC_KEY`
  - `LANGFUSE_SECRET_KEY`
  - `LANGFUSE_HOST` (`https://cloud.langfuse.com`)
- **Target File:** `backend/.env`
- **Purpose:** Traces Gemini prompts, token usage, latency, and agent reasoning steps.
- **Website:** [https://cloud.langfuse.com](https://cloud.langfuse.com)
- **Instructions:** Sign up for a free Langfuse account, create a project, and generate API credentials under Project Settings. Leave blank if not needed.

### ✉️ SMTP Email Service (Password Resets)
- **Variable Names:**
  - `SMTP_HOST`
  - `SMTP_PORT`
  - `SMTP_USER`
  - `SMTP_PASSWORD`
  - `MAIL_FROM`
- **Target File:** `backend/.env`
- **Purpose:** Sends automated account verification and self-service password reset emails.
- **Providers:** Any SMTP provider (SendGrid, Resend, Brevo, AWS SES, or Gmail App Password).
- **Note:** In local development, Duty Officers can generate password reset links directly in the dashboard UI without SMTP configured.
